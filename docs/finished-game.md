# 躲避作业：成品版操作手册

## 主角：星奈 SENA

原创 Q 版校园少女，蓝紫双马尾、水手服、红色领结和蓝色眼睛。站立时会眨眼、发尾轻摆，移动时交替迈步，冲刺和受伤时会改变表情。

角色使用 24 × 32 的像素图案，脚底对齐地面。头发与较大的脸部属于视觉造型；身体的碰撞区域独立定义，便于调整操作容错。

![星奈 SENA 放大预览](../assets/character-preview.png)

## 开始玩

双击项目里的 `play.command`。点击游戏窗口，使它获得键盘焦点。

标题画面按 **1** 选择 ARCADE（普通冒险）、**2** 选择 COZY（轻松冒险）、**3** 选择 EXAM（高难 Boss）、**D** 选择 DEMO（快速展示），再按空格或 Enter 开始。

快速展示直接双击 `demo.command`；高难 Boss 直接双击 `boss.command`。详细步骤见 [一分钟展示手册](showcase.md)。

| 按键 | 作用 |
| --- | --- |
| ← / → 或 A / D | 左右移动 |
| 空格 | 沿最后移动的方向冲刺；未移动时默认向右 |
| Boss 战按住 Z | 自动连续发射答案弹；靠近 Boss 的横向位置更容易命中 |
| 能力选择时 1 / 2 / 3 | 选择对应能力；或左右方向键选择、Enter 确认 |
| 标题或结束画面 C | 打开衣橱 |
| 衣橱 1～4 / 方向键 | 预览外观，Enter 装备可用外观，C 或 Esc 返回 |
| 标题画面 S | 循环切换可用外观 |
| DEMO 中 N | 跳到下一次升级，三次选完后进入 Boss |
| P / Esc | 暂停、继续 |
| M | 同时开关音乐与音效，记住静音设置 |
| 结束后 R / 空格 | 立即重开 |
| 暂停或结束后 Enter | 回到标题画面选择模式 |
| Q | 保存成绩并退出 |

## 看懂画面

- **白色作业**：需要躲避。红色标题的试卷更宽、下落更快。
- **顶部箭头与虚线**：作业即将落下的位置预告。
- **金色笔记**：接住后加 25 分。
- **薄荷绿色护盾**：接住后加 15 分，并抵挡一次撞击。已有护盾时再收集，加 35 分，仍保留一层护盾。
- **三颗红心**：撞击损失一颗。受伤后角色闪烁，短时间内不会再次损失生命。
- **左下 DASH 条**：充满时可以冲刺。冲刺持续约 0.2 秒，冷却约 2.5 秒；冲刺过程中可以穿过作业。
- **右下 SHIELD ON**：当前有护盾，角色周围也会出现绿色保护圈。

角色的碰撞区域略小于图案，靠边擦过有一点容错。

## 分数与难度

每存活一整秒获得 10 分。成功躲过一份作业加 10 分，近距离擦过额外加 5 分。冲刺穿过作业同样加 10 分。

冒险阶段每 12 秒提升一档难度，共八档；第二档起会出现较大的红色试卷。轻松模式的作业更慢、生成间隔更长。冒险开始后第 20、40、60 秒分别进行一次三选一升级；第 90 秒进入 Boss 战。

## 七种升级

| 卡片 | 实际效果 |
| --- | --- |
| WIND STEP | 冲刺冷却缩短 25% |
| FROST STEP | 冲刺时，将横向 90 像素以内的作业冻结 0.4 秒 |
| SHIELD NOVA | 护盾破裂时清除横向 100 像素以内的作业，计入躲避分数 |
| NOTE MAGNET | 接近角色的笔记会向角色移动 |
| PAPER RECLAIM | 冲刺撞碎作业后产生一份可收集笔记 |
| LAST FOCUS | 只剩一颗生命时，冲刺冷却缩短 40%；可以和 WIND 叠加 |
| EXAM EXPERT | 答案弹伤害加 1，发射间隔从 18 帧缩短到 14 帧 |

每项只能选择一次，一局共选三项。选择能力时暂停游戏计时。高难模式在战斗前连续选三项，随后直接进入 Boss。

## Boss：期末院长

Boss 会横向移动，答案弹命中才减少真实生命值。按住 Z 反击，同时用移动、冲刺和护盾躲避。生命耗尽或考试倒计时结束则失败。

| 阶段 | 行为 | 应对方法 |
| --- | --- | --- |
| 第一阶段：ROLL CALL | 标记玩家当前的位置，延迟落下试卷 | 看到预告后离开该位置 |
| 第二阶段：FIND THE GAP | 生成保留安全缺口的作业墙 | 找到空白通道，及时移动过去 |
| 第三阶段：FINAL SUBMISSION | 安全通道逐步横向移动，攻击更频繁 | 跟随通道，利用冲刺应急，继续反击 |

生命值降至三分之二、三分之一时切换阶段；每次切换清除旧攻击并留准备时间。普通 Boss 120 生命值、65 秒上限。EXAM 高难 Boss 210 生命值、70 秒上限，玩家仅两颗生命，预告更短、速度更快、缺口更窄。

击败 Boss 显示通关、能力组合和按剩余生命计算的 S/A/B 评级。普通通关额外得 500 分，高难通关额外得 2000 分。

## 四套外观与成就

| 外观 | 解锁条件 |
| --- | --- |
| SENA：蓝紫双马尾、水手服 | 初始拥有 |
| MINT：薄荷发色、浅色制服 | 正式游玩累计收集 25 份笔记 |
| LUNA：银发、深色制服 | 任意一次正式通关 |
| CRIMSON：红发、黑金制服 | 通关 EXAM 高难 Boss |

衣橱可以预览锁定外观，并显示解锁条件。DEMO 可以装备全部外观用于展示；展示成绩、笔记和通关不会增加正式成就。

正式模式分别保存最高分。每局结束、Q 退出或返回菜单时保存成绩、累计笔记和外观；静音设置也会保存。数据保存在本机 `data/save.json`，兼容旧版本的最高分。它属于个人存档，不随代码推送到 GitHub。存档无法写入时游戏仍可继续，结束画面会显示 `SAVE UNAVAILABLE`。

## 以后慢慢学习

不必一次读完整个程序。建议按这个顺序：

| 顺序 | 文件 / 位置 | 先理解什么 |
| --- | --- | --- |
| 1 | `game/config.py` | 改移动速度、冲刺冷却与初始生命 |
| 2 | `game/art.py` 的 `STUDENT`、`PIGTAIL` 与 `character_pixels()` | 如何把身体、发尾、眨眼和步行合成一帧角色 |
| 3 | `game/main.py` 的 `update_player()` | 按键如何改变坐标，冷却如何计时 |
| 4 | `spawn_items()` 与 `update_items()` | 生成、下落、碰撞、删除 |
| 5 | `start_game()`、`finish()`、`menu()` | 游戏状态与重新开始 |
| 6 | `game/audio.py` | 用音符字符串编写音乐与音效 |
| 7 | `game/storage.py` | JSON 存档与写入失败的处理 |
| 8 | `game/upgrades.py` 与 `game/main.py` | 能力描述如何对应具体效果 |
| 9 | `game/boss.py` | 生命值如何控制阶段，攻击如何留出安全缺口 |
| 10 | `game/progression.py` 与 `game/screens.py` | 成就、外观与菜单如何协作 |

原有第 1～3 课提供更短的版本，可以对照着读。修改参数后保存、关闭游戏、重新双击 `play.command` 才会生效。

### 第一个可选改动

在 `game/config.py` 把 `START_LIVES = 3` 改成 `4`，再启动普通或轻松冒险。角色会多一颗生命，HUD 也会多画一颗心。EXAM 和 DEMO 分别固定为两颗、五颗。一次只改一个参数，再用 Git 保存。

```sh
git add game/config.py
git commit -m "练习：调整成品版初始生命"
git push
```

这份成品的像素图形和音符均在源码中定义，没有外部素材下载步骤。
