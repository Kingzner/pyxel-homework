# 躲避作业：成品版操作手册

## 主角：星奈 SENA

原创 Q 版校园少女，蓝紫双马尾、水手服、红色领结和蓝色眼睛。站立时会眨眼、发尾轻摆，移动时交替迈步，冲刺和受伤时会改变表情。

角色使用 24 × 32 的像素图案，脚底对齐地面。头发与较大的脸部属于视觉造型；身体的碰撞区域独立定义，便于调整操作容错。

![星奈 SENA 放大预览](../assets/character-preview.png)

## 开始玩

双击项目里的 `play.command`。点击游戏窗口，使它获得键盘焦点。

标题画面按 **1** 选择 ARCADE（普通），按 **2** 选择 COZY（轻松），再按空格或 Enter 开始。两种模式分别保存最高分。

| 按键 | 作用 |
| --- | --- |
| ← / → 或 A / D | 左右移动 |
| 空格 | 沿最后移动的方向冲刺；未移动时默认向右 |
| P / Esc | 暂停、继续 |
| M | 同时开关音乐与音效，记住静音设置 |
| 结束后 R / 空格 | 立即重开 |
| 暂停或结束后 Enter | 回到标题画面选择模式 |
| Q | 保存成绩并退出 |

## 看懂画面

- **白色作业**：需要躲避。红色标题的试卷更宽、下落更快。
- **顶部箭头与虚线**：作业即将落下的位置预告。
- **金色笔记**：接住后加 25 分。
- **薄荷绿色护盾**：接住后加 15 分，并抵挡一次撞击。已有护盾时再收集，加 35 分，仍保留一层护盾。
- **三颗红心**：撞击损失一颗。受伤后角色闪烁，短时间内不会再次损失生命。
- **左下 DASH 条**：充满时可以冲刺。冲刺持续约 0.2 秒，冷却约 2.5 秒；冲刺过程中可以穿过作业。
- **右下 SHIELD ON**：当前有护盾，角色周围也会出现绿色保护圈。

角色的碰撞区域略小于图案，靠边擦过有一点容错。

## 分数与难度

每存活一整秒获得 10 分。成功躲过一份作业加 10 分，近距离擦过额外加 5 分。冲刺穿过作业同样加 10 分。

每 12 秒提升一档难度，共八档。难度影响作业的速度和出现频率；第二档起会出现较大的红色试卷。轻松模式的下落速度更低，生成间隔更长。

每局结束自动保存最高分；Q 退出或返回菜单也会保存当前成绩。最高分保存在本机 `data/save.json`。它属于个人存档，不随代码推送到 GitHub。没有存档时从零开始；存档无法写入时游戏仍可继续，结束画面会显示 `SAVE UNAVAILABLE`。

## 以后慢慢学习

不必一次读完整个程序。建议按这个顺序：

| 顺序 | 文件 / 位置 | 先理解什么 |
| --- | --- | --- |
| 1 | `game/config.py` | 改移动速度、冲刺冷却与初始生命 |
| 2 | `game/art.py` 的 `STUDENT`、`PIGTAIL` 与 `character_pixels()` | 如何把身体、发尾、眨眼和步行合成一帧角色 |
| 3 | `game/main.py` 的 `update_player()` | 按键如何改变坐标，冷却如何计时 |
| 4 | `spawn_items()` 与 `update_items()` | 生成、下落、碰撞、删除 |
| 5 | `start_game()`、`finish()`、`menu()` | 游戏状态与重新开始 |
| 6 | `game/audio.py` | 用音符字符串编写音乐与音效 |
| 7 | `game/storage.py` | JSON 存档与写入失败的处理 |

原有第 1～3 课提供更短的版本，可以对照着读。修改参数后保存、关闭游戏、重新双击 `play.command` 才会生效。

### 第一个可选改动

在 `game/config.py` 把 `START_LIVES = 3` 改成 `4`，再启动一局。角色会多一颗生命，HUD 也会多画一颗心。一次只改一个参数，再用 Git 保存。

```sh
git add game/config.py
git commit -m "练习：调整成品版初始生命"
git push
```

这份成品的像素图形和音符均在源码中定义，没有外部素材下载步骤。
