# 第 3 课：碰撞、计分和重新开始

这一课学习条件判断、函数和游戏状态。建议用 25～35 分钟完成。

代码在 `lessons/lesson_03.py`。每课有独立文件，可以随时回到第二课比较。第三课已经开启随机作业雨，每 45 帧生成一份作业。

## 1. 先体验完整流程

双击 `start-lesson-03.command`，或在项目目录运行：

```sh
./start-lesson-03.command
```

1. 按空格开始，方向键左右移动。
2. 躲过黄色作业，每存活一整秒得 1 分。
3. 主动接住一份作业，观察 `GAME OVER`、画面和分数停止更新。
4. 按 R 重新开始，确认角色回到中央、作业清空、时间和分数归零。
5. 随时按 Q 退出。

## 2. 第一个练习：改变计分规则

找到文件开头：

```python
SCORE_PER_SECOND = 1
```

改成 `10`，保存并重新启动。存活 3 整秒时，应显示 30 分。

计分代码在 `draw()`：

```python
seconds = play_frames // FPS
score = seconds * SCORE_PER_SECOND
```

`play_frames` 只在游戏进行时增加；`//` 是整除。30 帧计为 1 秒，59 帧仍是 1 秒。这里计算的是按帧折算的游戏时间；游戏结束后帧数不再增加，分数也就保持不变。

## 3. 第二个练习：看懂碰撞

`is_collision(homework)` 检查下面四个条件：

```python
player_x < homework["x"] + HOMEWORK_SIZE
and player_x + PLAYER_SIZE > homework["x"]
and player_y < homework["y"] + HOMEWORK_SIZE
and player_y + PLAYER_SIZE > homework["y"]
```

| 条件 | 意思 |
| --- | --- |
| 玩家左边 < 作业右边 | 玩家没有完全处于作业右侧 |
| 玩家右边 > 作业左边 | 玩家没有完全处于作业左侧 |
| 玩家上边 < 作业下边 | 玩家没有完全处于作业下方 |
| 玩家下边 > 作业上边 | 玩家没有完全处于作业上方 |

`and` 要求四个条件同时成立，意味着两块矩形在横向、纵向都有重叠。仅边缘接触不算碰撞。

动手把 `PLAYER_SIZE = 12` 改成 `20`，体验几次，再改回 `12`。较大的角色占据更多位置，更容易与作业重叠；玩家移动边界和碰撞区域都会使用新的尺寸。

不要删除其中一个条件：只检查左右重叠，会让还在头顶的作业提前结束游戏。

## 4. 第三个练习：找出重开的三个存档重置

先读 `start_game()`，找到并解释：

```python
player_x = (WIDTH - PLAYER_SIZE) // 2
homeworks = []
play_frames = 0
```

它们分别重置角色位置、清空作业、清零计时。再将 `player_x` 那行改成 `player_x = 0`。重新启动，按空格或 R 时，角色都会从左边开始。体验后可改回中央。

第一次开始和重开都调用 `start_game()`，所以只需修改一个函数，就能改变两处行为。

## 5. 三个游戏状态

| `state` 的值 | 此时处理什么 |
| --- | --- |
| `"ready"` | 等待空格开始 |
| `"playing"` | 移动、生成作业、检查碰撞、累积时间 |
| `"game_over"` | 显示最终分数，等待 R 重开 |

等待和结束状态中的 `return` 会提前退出当前帧的 `update()`，因此作业和时间暂停。`draw()` 仍然在运行，继续显示结束画面。

第二课用计时器控制生成；第三课使用 `play_frames % SPAWN_INTERVAL == 0`。`%` 求余数，因此 45、90、135……帧触发生成。重开后帧数清零，第一份作业仍在 45 帧后出现。
