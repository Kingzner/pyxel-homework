# 第 1 课：让角色动起来

建议用 20～30 分钟完成。先运行，再一次改一个参数。

## 1. 看见你的第一个游戏窗口

双击项目里的 `start.command`，或在项目目录运行 `./start.command`。

你应该看到蓝色背景、地面上的绿色方块，以及角色坐标 X。点击游戏窗口，按住左、右方向键。按 Q 退出。

如果出现报错，把终端中的报错发给我。

## 2. 今天只需认识这几行

```python
MOVE_SPEED = 2
PLAYER_COLOR = 11
PLAYER_SIZE = 8
```

这三个名字分别存着速度、颜色和尺寸。后面的数字是它们的值。

画面的左上角是坐标原点。x 越大，位置越靠右；y 越大，位置越靠下。

```python
player_x += MOVE_SPEED
```

它相当于 `player_x = player_x + MOVE_SPEED`：在原来的横坐标上加上移动速度。

`update()` 处理按键和位置；`draw()` 按照当前的位置画出角色。当前设置是每秒更新 30 次，因此速度为 2 时，持续向一个方向移动、且没有触及边界的角色每秒约移动 60 像素。

## 3. 三个动手练习

每次先预测结果，修改并保存，再按 Q 退出旧窗口、重新运行。

| 练习 | 修改 | 观察什么 |
| --- | --- | --- |
| 1：加速 | 把 `MOVE_SPEED = 2` 改成 `MOVE_SPEED = 4` | 横穿屏幕是不是更快了？ |
| 2：换颜色 | 把 `PLAYER_COLOR = 11` 改成 `PLAYER_COLOR = 8` | 方块从绿色变成了什么颜色？ |
| 3：变大 | 把 `PLAYER_SIZE = 8` 改成 `PLAYER_SIZE = 12` | 方块是否变大？它还能完整停在右边缘吗？ |

Pyxel 默认颜色编号：0 黑、1 深蓝、2 紫、3 深绿、4 棕、5 灰蓝、6 浅灰、7 白、8 红、9 橙、10 黄、11 浅绿、12 蓝、13 灰紫、14 粉红、15 浅桃色。

初始值是速度 2、颜色 11、尺寸 8，想恢复时改回即可。

## 4. 解释自己的修改

完成后，用自己的话回答：

1. 按右键时，为什么要给 `player_x` 加一个数字？
2. 如果希望角色更慢，你会修改哪里？
3. 右边界为什么是 `WIDTH - PLAYER_SIZE`？

能解释第一题，就有了学习下一课的起点。
