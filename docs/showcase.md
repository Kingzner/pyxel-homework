# 快速展示：约一分钟讲清项目

## 最快入口

双击 **`demo.command`**，打开快速展示模式。先关闭旧版本游戏窗口，避免操作到旧窗口。

标题画面已选中 DEMO。它提供五颗生命、初始护盾、全部外观预览，以及 N 键的流程推进。

## 现场操作顺序

| 步骤 | 操作 | 可以怎么介绍 |
| --- | --- | --- |
| 1：角色与外观 | 标题画面按 C，按 1～4 预览，Enter 装备 | “这是原创像素角色。四套外观通过收集与通关成就解锁，这里可以快速预览。” |
| 2：基本操作 | 空格开始，A/D 移动，空格冲刺，按住 Z 击碎作业 | “角色能移动、冲刺和主动射击；攻击、擦险和冲刺会积攒连击与专注。” |
| 3：局内选择 | 按 N，选 1/2/3；重复三次 | “每次三选一，不同能力可以组合，改变玩家的打法。” |
| 4：Boss 战 | 再按 N 进入 Boss，Enter 开战 | “Boss 有真实生命值、时间限制，以及按血量切换的三个阶段。” |
| 5：反击和通关 | 按住 Z 发射答案弹，移动躲避；专注满格按 X | “点名需要移动，作业墙要找缺口；专注爆发能清场并追加伤害。” |
| 6：成果 | 展示结算中的分数、连击、击碎数量和能力组合，按 Enter 进入结局 | “正式游玩的成绩、解锁外观和语言偏好会保存到本机。胜利后还有完整结局。” |

展示过程中随时按 **L**，可以把游戏里的标题、操作提示、能力卡、Boss 和结算在中文与英文之间切换。

展示模式的外观是预览权限，成绩和通关不会计入正式记录或成就；静音设置可以正常保存。

不按 N 时，也会在第 2、6、10 秒自动展示三次能力选择，第 14 秒进入 Boss。能力选择和暂停期间，游戏计时停止。

## 展示高难版本

双击 **`boss.command`**，直接进入 EXAM 高难挑战的能力选择。

连续完成三次三选一后进入 Boss 战，不用等待冒险模式的 90 秒准备阶段。按 Enter 跳过登场提示，按住 Z 反击。

| 项目 | 普通 Boss | EXAM 高难 Boss |
| --- | --- | --- |
| 初始生命 | 冒险模式的剩余生命 | 2 颗 |
| Boss 生命值 | 120 | 210 |
| 时间上限 | 65 秒 | 70 秒 |
| 攻击预告 | 52 帧 | 32 帧 |
| 初始下落速度 | 1.8 像素/帧 | 2.8 像素/帧 |
| 点名攻击 | 两张试卷 | 三张试卷 |
| 安全缺口 | 第二阶段 76 像素；第三阶段 70 像素 | 第二阶段 48 像素；第三阶段 44 像素 |

速度随阶段增加。Boss 不会在预告期间造成伤害；切换阶段会清除旧攻击，再给出准备时间。躲避与反击需要同时进行，生命耗尽或时间到都会失败。

## 备用启动命令

在项目目录执行：

```sh
.venv/bin/python -m game.main --showcase
.venv/bin/python -m game.main --boss
.venv/bin/python -m game.main --showcase --seed 42
```

## 简短项目介绍

> 我用 Python 和 Pyxel 做了一个原创像素动作游戏。它包含角色动画、主动射击、连击与专注爆发、三选一技能组合、三阶段 Boss、成就外观解锁，以及本机自动存档。场景状态、攻击编排和战斗资源拆成独立模块，演示模式还支持固定随机种子。

## 仓库首页动图

首页动图由游戏自身的 Pyxel 绘制代码生成，使用固定随机种子，剪辑了标题、战斗、能力选择、Boss、结算和结局画面。它是流程预览，完整游玩请按上面的步骤操作。

在项目根目录执行：

```sh
.venv/bin/python -m tools.record_showcase
```

脚本在无窗口模式下录制，不读取或改动玩家存档；默认更新 `assets/showcase.gif`，也可以用 `--output` 指定输出路径。
